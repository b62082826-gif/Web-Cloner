    What it does

    One link in, a working copy out.

    WebGrabber reads the page, finds every file it needs, downloads them side by side and rewrites the links so nothing points back to the internet.

    Many files at once

    Pages, stylesheets, scripts, fonts and images download in parallel, so a large page finishes in seconds. Anything that fails keeps its live link instead of breaking the page.

    Links that work offline

    Fonts and backgrounds inside CSS are saved too, and their URLs are rewritten.

    How it works

    Three steps, in this order.

    1. Paste the address

      Type example.com or paste a full link. The bar under the field fills when the link looks valid.

    2. Choose a folder

      Pick where copies go. WebGrabber remembers it, and your recent sites, for next time.

    3. Press Download

      Watch it run, then open the copy in your browser or jump straight to the folder.

    Questions

    Quick answers.

    Is WebGrabber free?

    Yes. The download is free. Get the latest build from the download section below or from GitHub Releases.

    Which systems does it run on?

    Windows 10 and 11, 64-bit. It needs the Microsoft Edge WebView2 runtime, which comes with Windows 11 and current Windows 10.

    Why does Windows show a blue warning?

    The app is not code-signed yet, so Windows warns about it. Choose More info, then Run anyway. If you are unsure, the full source code is on GitHub.

    Separate files or a single file?

    Separate files gives you a tidy folder with css, js, images and fonts that you can open, edit and host. A single file packs everything into one .html, which is easier to send but larger.

    What happens if a file fails to download?

    That file keeps its original online link, so the page does not break. Everything else is still saved and rewritten for offline use.

    How do updates work?

    On start, WebGrabber checks for a newer build. If there is one, a banner lists what changed, and one click installs it and restarts the app.

    Where are my copies saved?

    In the folder you choose, and WebGrabber remembers it. Each copy gets its own folder named like example.com_20261124_141502, or a single example.com.html file.

    Can I copy any website?

    Only grab sites you have the right to copy. WebGrabber saves what a page loads, but that does not give you permission to reuse it.
